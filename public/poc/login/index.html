Design notes

How the flow reads

Familiar first step

"Open Isol on your phone, link a device, point at the code" is the pattern people already know from other messaging apps, so the screen looks like it.

The code is temporary, and says so

Under the QR: the temporary key it holds and a ring counting down to a fresh code. The key only lives in this tab; a new code means a new key and a new magnet.

Both screens tell the same story

Connecting shows the same three steps on both: code scanned, peers found in the swarm, secure channel. The dotted line turns solid once the channel is up.

A code to compare

Before anything is shared, both screens show the same 6-digit code, made from both keys. Checking it is what stops someone who photographed the QR from linking instead of you. The phone is where you say yes.

The phone stays in charge

The sheet says plainly what linking gives the browser: your identity, your chats. Linked browsers appear in the phone's list with Unlink at hand.

Failures with a way out

An expired code blurs with "New code" on top. A decline or a failed connection each say what happened and offer the next step, not just an error.
