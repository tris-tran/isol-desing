Design notes

Why it looks like this

The QR is a secret

It holds the private key, so it gets the same dark plate and "Keep secret" tag as the words and key in Create identity. It starts covered, and the cover says plainly what scanning it does.

The Isol QR

The code is drawn by isol-qr.js, the halftone over Isolde in the house style, up to 480px square. It holds the identity as a small JSON payload (private and public key), well inside the 1,500-byte limit.

Shown for a minute

Once shown, the QR hides itself after 60 seconds, with a bar counting down. "Hide now" is right next to it.

Link and code travel apart

The torrent only holds an encrypted file. The link is light (fine to send), the transfer code is dark (secret). The other browser needs both, and the code should go a different way than the link.

Seeding is visible

While this browser seeds, a status bar with a pulsing dot shows peers and progress, with Stop always at hand. Seeding stops by itself once the file arrives, or after 10 minutes.

Mock data

The identity and its QR are real (isol's crypto, isol-qr.js). The magnet link and transfer code are made up for the design. In the file mode the demo plays itself: a peer joins after a few seconds.
