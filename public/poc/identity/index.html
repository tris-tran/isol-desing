The rules

One identity, one way of showing it

The key is who it isEvery piece shows the key, or can reach it in one tap: short key, key colours, or the full key.
Names, in this order"You" for yourself · the name you gave them · their own name in “quotes” · the short key when there's no name at all.
Quotes mean "they say so"A name you haven't confirmed is always quoted. Only names you chose appear bare.
Vermilion is yoursYour avatar is always Vermilion, with the curtain lines from the print. No one else's avatar ever is, so you can't be confused with anyone in a list, a search or a comparison.
Avatars can be copied, key colours can'tThe avatar colour comes from the first characters of a key, which a look-alike can match. Key colours read the whole key, so they always tell two keys apart.
Marks travel with the nameGilt seal for verified, Olive heart for trusted, Madder warning for a look-alike, everywhere the name appears.
